💡 Cheatsheet Perintah Docker Esensial

Klik perintah di bawah untuk melihat penjelasan detailnya
docker build -t learndocker-app . Build image dari Dockerfile
docker run -d -p 3000:3000 learndocker-app Jalankan container di background dengan port mapping
docker ps -a Lihat semua container yang aktif & nonaktif
docker logs -f <container_id> Intip logs/keluaran dari aplikasi di container
docker stop <container_id> Hentikan container yang sedang berjalan
docker compose up -d Jalankan seluruh service sesuai docker-compose.yml
Klik salah satu perintah di atas untuk mempelajari parameter dan fungsinya.
